# Archived Go/Wails prototype

This is the initial configuration-only prototype. It is not the active application and has not been built in the current environment. Its original `frontend/dist` embedding path no longer points to the active frontend.

The supported runtime is now `desktop/` (Electron) and `server/` (Node.js), sharing the React UI in `frontend/`. The switch allowed the desktop and networking backend to be built and tested with tools available in the development environment. Do not use this archive to build a release.
